## About Me

I'm a computer science student building toward a future in software engineering, with a growing focus on AI and full-stack web development. I learn by building — picking a project slightly out of reach, breaking it, and figuring out why. Right now that means deepening my grip on React and Node.js while working through the fundamentals of machine learning on the side.

I'm currently applying to bachelor's programs, and I'm always up for collaborating on beginner-friendly or open-source projects. If you want to talk web development, Git and GitHub workflows, or what it's like starting out in CS, my inbox is open.
